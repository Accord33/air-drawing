# Air Drawing MVP

SPEC.md に基づく、HTML/CSS/Vanilla JS の静的アプリです。人差し指を伸ばし、中指・薬指・小指を曲げている間だけ、人差し指先に赤い線（`#FF0000`、表示上 5px）を描きます。親指は判定しません。左右どちらの手も使え、同時に認識するのは片手です。

## ローカルで開く

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

PC の Chrome で `http://localhost:8000` を開き、カメラを許可してください。公開環境では HTTPS が必要です。ファイルを直接開く方法は使いません。

映像は左右反転せず、縦横比を保って画面内に最大表示します。余白は黒色です。透明 Canvas は映像の表示領域と一致します。手を下ろす・見失う・認識に失敗する場合は線を切り、再認識後は新しい線を始めます。線は画面サイズを変えても保持され、リロードで消えます。保存、リセットボタン、バックエンド、DB はありません。

## 配信するファイル

配信対象は **`dist/` の以下の3ファイルのみ**です。ビルドや依存パッケージのインストールは不要です。

- `index.html`
- `app.js`
- `style.css`

リポジトリ全体を公開しないでください。環境設定・秘密情報は配信対象に含みません。

MediaPipe Tasks Vision **0.10.14** の ES module / WASM を jsDelivr から、Hand Landmarker **float16/1** モデルを Google の静的ストレージから読み込みます。初回起動時はインターネット接続とこれらの配信元へのアクセスが必要です。カメラ映像・ランドマークの解析と描画はブラウザ内で行い、映像や手の情報を外部送信しません。モデルの読込失敗やカメラ拒否は画面に表示します。

## 確認結果

`node --check dist/app.js` は成功しました。ローカルHTTPサーバーで `index.html`・`app.js`・`style.css` を配信し、ブラウザーでページ、映像要素、Canvasの表示を確認しました。配信ZIPには `dist/` の3ファイルだけが含まれ、`.env` はGitとZIPの両方から除外されています。

自動ブラウザー環境ではカメラを利用できなかったため、実カメラでのジェスチャー認識・描画動作は未確認です。利用するPCのChromeで次を確認してください。

1. カメラ許可後の映像が左右反転せず、線と指先の位置が一致すること。
2. 左右それぞれの手で、指定ジェスチャーだけが描画を開始し、親指の位置は判定に影響しないこと。
3. 赤線の追従・保持、指を下ろした時・手が消えた時・再認識した時の線の分離。
4. リサイズ時の位置一致・保持と、リロード時の消去。
5. カメラ拒否、モデル読込失敗時の簡潔なエラー表示。
